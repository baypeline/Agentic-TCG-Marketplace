# 공통 모션

사용자의 요청에 따라 기존 ‘카드 hover 이동 없음’ 규칙을 대체합니다. 순백 배경·기존 레이아웃·Emotion 선언 위치는 유지합니다. UI/UX Pro Max의 Reduced Motion·Excessive Motion 가이드를 참고해 사용자가 조작한 요소에만 반응합니다.

## 패널

- 데스크톱은 분할 그리드의 오른쪽 열을 0 → 360px로 280ms 전환합니다. 이 전환은 실제 본문 폭도 바꿔야 하므로 레이아웃 전환을 사용합니다. 대화 본문은 360px을 유지하고 외부 영역에서 잘라 폭이 변하는 동안 문장이 계속 줄바꿈되는 것을 줄입니다.
- 패널은 opacity와 20px 수평 이동을 함께 전환합니다. 모바일은 같은 영역에서 본문과 대화를 바꾸며 이동을 12px로 줄입니다. 팝업으로 바꾸지 않습니다.
- 닫기에서도 DOM을 유지하고 visibility를 전환 완료 뒤 숨겨 퇴장 효과를 보존합니다. inert·aria-hidden은 닫기 즉시 적용하고 포커스는 열기 버튼으로 돌립니다. 포커스로 인한 자동 스크롤은 막습니다.
- CSS transition으로 빠르게 반대로 누르는 경우에도 현재 위치에서 반전하며 JS 타이머나 완료 콜백에 상태를 의존하지 않습니다. 헤더 폭은 패널 상태와 관계없이 유지합니다.

## 카드와 작은 피드백

- 실제 포인터 hover가 가능한 장치에서 연결된 카드 이미지에만 위로 4px·1.015배 확대를 220ms 적용합니다. 키보드 focus-visible에도 동일하게 반응하며 터치의 누름은 0.99배로 표현합니다.
- 카드명·가격은 움직이지 않고 상세 큰 이미지·거래 표 썸네일도 제외합니다. 링크의 포커스 테두리는 유지합니다.
- 링크·버튼은 색상·배경·테두리 색을 150ms 전환합니다. 새 대화 메시지는 6px 상승·opacity 전환으로 220ms 등장하며 가짜 응답·처리 중 상태를 만들지 않습니다.
- `theme.motion`에서 시간과 easing을 관리합니다. 자동 반복·페이지 진입의 일괄 stagger·3D 회전·반짝임은 추가하지 않습니다.

## 접근성

prefers-reduced-motion에서는 패널 전환·이동과 메시지 등장을 끄고 카드의 변형도 제거합니다. 전역 transition·animation 제한도 유지합니다. 모션 유무와 관계없이 열림 상태·버튼·기존 안내 문구가 기능을 전달합니다.
