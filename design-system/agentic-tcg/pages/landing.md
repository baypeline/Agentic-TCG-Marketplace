# 랜딩 — 에이전트 거래 과정

이 문서는 MASTER.md의 랜딩 구조를 대체합니다. 순백 배경·코랄 버튼·Pretendard·Emotion 선언 위치와 공통 레이아웃은 기존 기준을 따릅니다.

## 목적과 구성

카드 검색에 챗봇을 붙인 서비스가 아니라, 사용자가 정한 조건 안에서 Agent가 구매를 수행하는 플랫폼임을 설명합니다. UI/UX Pro Max의 `Interactive Product Demo` 검색에서 확인한 `Product Demo + Features` 패턴을 적용합니다. 영상·자동 진행 없이 네 개의 버튼으로 각 단계를 살펴봅니다.

1. 소개: ‘카드 구매는 AI 에이전트에게’. 구매자는 `/agent`의 ‘구매 조건 정하기’, 판매자는 `/collection#owned-cards`의 ‘보유 카드 판매하기’로 진입합니다. 카드 검색은 보조 동선입니다. 구매 위임과 직접 판매 등록의 역할 차이 및 현재 미리보기 범위를 바로 안내합니다.
2. 설명용 거래 예시: ‘영문 피카츄 한 장을 10 USDC 이하로 구해줘’라는 요청을 조건 확인 → 매물 검토 → 결제 확인 → 카드 반영으로 나누어 설명합니다.
3. 판매 안내: 보유 카드 선택 → 고정가 등록 → 예약·결제 확인 → 판매 완료를 설명하고 내 카드 목록으로 연결합니다. 판매자에게 USDC를 지급·출금하지 않고 내부 모의 장부로 기록한다는 안내를 함께 제공합니다. 구매자 결제 수취인은 플랫폼 지갑입니다.
4. 사용자 통제: 총예산·1회 한도·허용 카드, 신규 거래 중지, 주문·결제·로그 확인을 관련 화면에 연결합니다.
5. 카드 탐색: 실제 카탈로그 카드 최대 네 장을 상세로 연결합니다. 거래 조건을 정하기 위한 보조 콘텐츠로 배치합니다.

## 데이터와 동작

- 예시의 10 USDC 한도·8 USDC 매물은 합성 설명입니다. 실매물·적정가·체결 결과로 표시하지 않습니다.
- 단계 버튼은 로컬 설명만 전환하고 정책 저장·Agent 실행·주문·서명·송금 요청을 하지 않습니다. 자동 재생이나 자동 포커스 이동은 없습니다.
- 결제 단계는 Base Sepolia 테스트 USDC → 플랫폼 수납 지갑 → 정산 성공 확인을 설명합니다. 마지막 단계는 서비스 내부 카드 소유권 반영이며 NFT 전송으로 설명하지 않습니다.
- 기존 카탈로그 API 실패·빈 결과가 거래 설명과 조건 설정 진입을 지우지 않습니다. 카드 자료 누락과 가상 예시를 혼합하지 않습니다.
- 카드 갤러리는 UUID 중복을 제거하고 출처 자료의 세트·번호·언어를 유지합니다. 참고 시세는 상세에서 확인하며 랜딩 예시 금액과 연결하지 않습니다.

## 배치와 접근성

넓은 본문에서는 소개와 거래 예시를 2열로 배치하고 본문 컨테이너 폭 880px 이하에서는 소개 뒤에 예시를 둡니다. 실제 본문 폭은 사이드 대화 패널의 영향을 받습니다. 통제 안내와 갤러리는 650px 이하에서 각각 1열·2열로 바뀝니다. 단계 선택은 네이티브 버튼·aria-pressed·aria-controls를 사용하고 변경 내용은 polite live region으로 알립니다. 단계별 제목·설명·확인 항목을 텍스트로 제공하며 색만으로 선택 상태를 전달하지 않습니다.

Emotion styled 선언은 컴포넌트 아래에 둡니다. 배경은 순백이며 장식용 눈썹 제목·실시간처럼 보이는 가상 로그·자동 애니메이션·후기·성과 수치를 추가하지 않습니다.

## 공통 탐색과 에이전트 패널

랜딩에는 카드 검색·매물·내 카드 등 서비스 탭 줄을 두지 않습니다. 상단은 브랜드 홈 링크, 마켓 진입, 에이전트 열기·닫기로 구성합니다. 실제 서비스 화면에 진입한 뒤 본문 상단의 탐색 메뉴로 이동합니다. 모바일의 ‘카드 탐색 / 에이전트 대화’ 탭도 제거합니다.

에이전트는 처음에는 닫혀 있고 Zustand persist로 브라우저의 마지막 열림·닫힘 상태만 기억합니다. 최초 SSR은 닫힌 상태이며 마운트 이후 복원합니다. 데스크톱에서는 사이드 분할, 모바일에서는 본문과 대화 영역을 전환하며 팝업을 사용하지 않습니다. 상단 버튼은 aria-expanded·aria-controls로 상태와 제어 대상을 알립니다. 내부 닫기·Escape를 지원하고 직접 열거나 닫을 때 포커스를 연결합니다. 대화·정책·거래 내용은 영속화하지 않습니다.

## 판매 화면의 연결

`SellerGuide`는 랜딩과 내 카드에서 같은 판매 과정과 대금 안내를 제공합니다. 내 카드의 목록 앵커는 고정 메뉴에 가리지 않도록 scroll-margin을 둡니다. 판매 대금 안내는 등록 폼의 제출 버튼 전에도 표시합니다. 내 매물 링크는 `/marketplace?owner=me`로 연결하고 매물 목록에서는 전체·내 매물·다른 판매자 매물을 구분합니다.

보유 중에는 판매 등록, 판매 중에는 취소 후 재등록으로 가격 변경, 예약 중에는 변경 없이 결제 확인 대기, 이전 완료에는 거래 내역 확인을 안내합니다. 미구현 가격 수정·판매 Agent·실제 지급 기능을 암시하지 않습니다. 거래 관리의 판매 수익 행은 ‘입금’ 대신 ‘판매 수익 기록 (모의)’로 표시하며 블록체인 입금·재시도 기능과 분리합니다.
