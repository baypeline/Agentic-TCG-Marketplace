# 한국어판 이미지와 거래 시드

공식 [포켓몬 카드 게임 카드 검색](https://pokemoncard.co.kr/cards)의 상세 페이지와 한국어판 수집 원본을 이름·세트·번호로 대조했습니다. 와일드포스(SV5K) 12종의 공식 이미지를 연결합니다.

| --- | --- | --- |
| 001 | 로젤리아 | BS2024004001 |
| 002 | 로즈레이드 | BS2024004002 |

| 008 | 엘풍 | BS2024004008 |

상세 URL은 `https://pokemoncard.co.kr/cards/detail/{공식 카드 ID}`입니다. 이미지 URL·제품명·인쇄 번호·검증 시각·SHA-256·응답 크기를 `packages/db/fixtures/catalog/official-images.json`에 기록합니다. 이미지 바이너리와 페이지 HTML은 Git에 넣지 않습니다. 이미지 권리는 원 권리자에게 있으며 공개 페이지 접근이 재배포 허락을 의미하지 않습니다.

## 복원과 갱신

```powershell
pnpm db:migrate
pnpm db:seed:collected
pnpm demo:seed
```

Git의 JSON만 읽어 복원합니다. 수집 카드 시드는 원본 삽입 후 이미지 출처를 연결합니다. 이미 수집 카드가 있다면 `pnpm db:seed:images`만으로 이미지 연결을 재현할 수 있습니다. 거래 DB의 체인·통화와 현재 환경 설정이 일치해야 합니다.

```powershell
pnpm cards:images:ko
pnpm cards:images:ko --seed
```

갱신은 `official-image-targets.json`의 최대 15개 명시적 매핑만 순서대로 조회합니다. 이름·제품·세트 경로·인쇄 번호가 일치해야 하며 공식 호스트 이외의 URL, 리다이렉트, 예상 외 경로·응답 형식은 거부합니다. 실제 WebP 시그니처도 확인합니다. 모든 대상이 성공한 뒤 JSON을 교체하며 `--seed`일 때 DB에 연결합니다.

## 원본과 거래 재고

`catalog.CardImageReference`는 카드 UUID에 이미지 근거를 연결합니다. 수집 원본의 판본·보존 상태·가격은 이 작업으로 확정되지 않습니다. 조회 DTO의 `CardVariant.imageSource`는 쓰기 입력으로 사용하지 않습니다.

`fixtures/demo/korean-scenarios.json`에는 원본과 다른 고정 UUID를 가진 거래용 카드 12종을 정의합니다. NORMAL/NM 속성·MOCK 참고 가격·카드당 매물 2개를 구성합니다. 마루의 매물 가격은 3~13 tOKRW이며 실제 국내 시세나 USD 환율이 아닙니다. 공식 이미지는 인쇄본을 식별하지만 개별 실물의 보존 상태를 증명하지 않습니다.

`readDemoScenarios(chain, true)`와 시드 CLI는 한국어판을 포함한 15종을 사용합니다. 기존 공개 함수의 기본값과 RWA 발행 스크립트는 기존 3종을 유지합니다. 이번 한국어판 매물은 일반 DB 재고이며 NFT 발행·온체인 매물 등록을 하지 않습니다. 구매는 기존 마루 x402 결제 경로를 사용합니다.

시드는 기존 소유자·판매 완료 상태·체결·소비 예산을 초기화하지 않습니다. 구매 시 수정되지 않은 초기 정책만 기존 3종에서 15종으로 확장하며 사용자 지정 정책은 자동 확장하지 않습니다. 참고 가격과 실제 활성 매물은 별개로 조회하며 매물 소진 시 새 소유권을 임의 생성하지 않습니다.
