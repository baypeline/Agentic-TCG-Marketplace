# 카탈로그 선별 기준

사용 화면은 수집 데이터 전체를 나열하지 않고 정보가 갖춰진 카드를 선별합니다. DB 원본·fixture·기존 거래·NFT 연결은 삭제하거나 변경하지 않습니다.

## 기본 설정

```dotenv
CATALOG_MODE=curated
CATALOG_MAX_CARDS=12
```

카드 검색과 랜딩은 선별된 목록을 사용합니다. 검색어에 맞는 후보를 평가하고, 실제 한국어판 → 재고 연결 → 세트·카드 번호 순으로 정렬해 최대 개수와 요청 limit를 적용합니다. 한국어판 12종이 있어도 피카츄 검색으로 기존 영어판을 찾을 수 있습니다. 한글 표시 이름이 있는 영어판을 한국어판으로 간주하지 않습니다.

선별 조건은 다음과 같습니다.

- 유효한 UUID·카드 이름·세트·카드 번호·판본·보존 상태.
- `UNSPECIFIED`, `UNKNOWN`, 빈 필드 제외.
- HTTPS 이미지 URL과 KO/EN 인쇄 언어.
- 현재 가격 모드에 맞는 양수 가격 표본, 미래 시각 제외.
- Mock 모드는 해당 카드의 MOCK 표본만 사용하며 고정 시연 가격은 만료시키지 않음.
- Market 모드는 최근 72시간의 TCGplayer USD 시장 집계가만 사용. 영어판 가격을 한국어판에 연결하거나 빈 가격을 새로 생성하지 않음.

공식 이미지 출처가 검증된 한국어판 원본은 가격·보존 상태가 없어도 `catalogRole=REFERENCE`로 열람할 수 있습니다. 화면에서는 가격 대신 공식 카드 정보를 제공합니다. 같은 인쇄본의 거래용 카드가 있으면 원본을 중복 노출하지 않습니다. 수집 시 실제 WebP 응답·해시를 검증하지만 외부 이미지 서버의 지속적인 가용성은 보장하지 않습니다. 가격 평가의 표본·환율·판본 검증 로직은 별도로 유지합니다.

## 현재 데이터 상태

수집 원본 410종(EN 171·KO 239)은 유지합니다. 한국어판 와일드포스 12종에 공식 사이트의 이름·세트·번호를 대조한 이미지와 출처를 별도 연결했습니다. 나머지 한국어판에 이미지나 가격을 추정해서 넣지 않습니다.

시연 모드는 기존 영어판 3종과 새 한국어판 거래용 12종을 사용합니다. 한국어판은 원본과 다른 UUID에 NORMAL/NM 시연 속성·MOCK 가격·24개 판매 재고를 구성합니다. 기본 카탈로그는 이 한국어판 12종을 우선 노출합니다. 기존 영어판·NFT·소유권·체결·예산 소비 내역은 유지하며 새 카드를 자동 NFT화하지 않습니다. 수집과 재현 절차는 [한국어판 이미지와 거래 시드](korean-card-images.md)를 참고하세요.

## 원본 조회와 검증

수집·한국어 이름 연결·가격 수집을 검증할 때는 `CATALOG_MODE=all`을 사용합니다. 선별에서 빠진 카드도 `GET /api/cards/:id`로 직접 조회할 수 있어 기존 보유 카드·거래 상세가 사라지지 않습니다. 모드를 변경하면 API를 재시작하세요.

```powershell
pnpm --filter @tcg/aggregator test
pnpm --filter @tcg/api test
pnpm --filter @tcg/web test
```

테스트는 누락 정보·0원·미래/오래된 시장 가격 제외, 실제 한국어판 우선, 검색 limit 이전 선별, 제외된 카드의 직접 상세 조회 보존을 확인합니다. API의 기존 수집 통합 테스트는 원본 검증 목적을 명시해 `all` 모드로 실행합니다.
