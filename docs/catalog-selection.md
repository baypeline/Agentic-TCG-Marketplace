# 카탈로그 선별 기준

사용 화면은 수집 데이터 전체를 나열하지 않고 정보가 갖춰진 카드를 선별합니다. DB 원본·fixture·기존 거래·NFT 연결은 삭제하거나 변경하지 않습니다.

## 기본 설정

```dotenv
CATALOG_MODE=curated
CATALOG_MAX_CARDS=12
```

카드 검색과 랜딩은 선별된 목록을 사용합니다. Aggregator에서 전체 후보를 평가하고, 실제 한국어판 → 재고 연결 → 세트·카드 번호 순으로 정렬해 최대 개수를 선택한 뒤 검색어와 요청 limit를 적용합니다. 한글 표시 이름이 있는 영어판을 한국어판으로 간주하지 않습니다. 랜딩도 한국어 검색어를 사용하고 한국어판을 우선 유지합니다.

선별 조건은 다음과 같습니다.

- 유효한 UUID·카드 이름·세트·카드 번호·판본·보존 상태.
- `UNSPECIFIED`, `UNKNOWN`, 빈 필드 제외.
- HTTPS 이미지 URL과 KO/EN 인쇄 언어.
- 현재 가격 모드에 맞는 양수 가격 표본, 미래 시각 제외.
- Mock 모드는 해당 카드의 MOCK 표본만 사용하며 고정 시연 가격은 만료시키지 않음.
- Market 모드는 최근 72시간의 TCGplayer USD 시장 집계가만 사용. 영어판 가격을 한국어판에 연결하거나 빈 가격을 새로 생성하지 않음.

이는 검색 노출 기준입니다. 가격 평가의 표본·환율·판본 검증 로직을 대신하지 않습니다. 이미지 URL의 존재만 검사하며 외부 이미지 서버의 지속적인 가용성을 보장하지 않습니다.

## 현재 데이터 상태

2026-11-28 마루 DB의 카드 413종을 확인했습니다. 한국어판 239종에는 이미지와 가격이 없으며, 수집 원본의 판본·보존 상태도 미확정입니다. 현재 기준을 통과하지 못하므로 우선 노출을 위해 이미지를 다른 언어판으로 대체하거나 가격을 만들어 넣지 않습니다.

현재 시연 모드는 기존 피카츄·리자몽·이브이 세 종의 거래 시나리오 범위를 유지합니다. 세 종에는 이미지·판본·상태·고정 가격이 갖춰져 있어 그대로 노출합니다. NFT·기존 소유권·거래와 카드 UUID는 유지합니다. 한국어판을 실제로 앞에 보여주려면 그 판본의 이미지·확인된 속성·가격 데이터를 보강해야 합니다. 완전한 한국어판이 선별 후보에 포함되면 영어판보다 먼저 선택됩니다. 시연 모드 자체의 카드 ID 제한은 유지하므로 시나리오 확대 시 해당 목록도 함께 조율해야 합니다.

## 원본 조회와 검증

수집·한국어 이름 연결·가격 수집을 검증할 때는 `CATALOG_MODE=all`을 사용합니다. 선별에서 빠진 카드도 `GET /api/cards/:id`로 직접 조회할 수 있어 기존 보유 카드·거래 상세가 사라지지 않습니다. 모드를 변경하면 API를 재시작하세요.

```powershell
pnpm --filter @tcg/aggregator test
pnpm --filter @tcg/api test
pnpm --filter @tcg/web test
```

테스트는 누락 정보·0원·미래/오래된 시장 가격 제외, 실제 한국어판 우선, 검색 limit 이전 선별, 제외된 카드의 직접 상세 조회 보존을 확인합니다. API의 기존 수집 통합 테스트는 원본 검증 목적을 명시해 `all` 모드로 실행합니다.
